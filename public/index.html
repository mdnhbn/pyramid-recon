PHASE 0
Scope & consent
Python-এর domain validation এবং UI-তে দেওয়া authorization/provider consent যাচাই। কোনো network tool চলে না।

            
PHASE 1
Certificate transparency
Custom bounded HTTP helper দিয়ে crt.sh JSON lookup। এটি আলাদা OSINT scanner নয়।

            
PHASE 2
DNS lookup
dnspython দিয়ে সর্বোচ্চ ৪টি name-এর A/AAAA রেকর্ড resolve; public IP ছাড়া বাদ।

            
PHASE 3
Root homepage check
Python socket, ssl ও http.client; resolved public IP-তে pin করে root-এর একটি GET, redirect অনুসরণ নয়।

            
PHASE 4
Technology hints
Built-in html.parser, response header ও কয়েকটি HTML marker মিলিয়ে সম্ভাব্য fingerprint।

            
PHASE 5
Robots & sitemap
একই সীমিত HTTP helper দিয়ে root-এর শুধু /robots.txt ও /sitemap.xml পড়া হয়; path brute force হয় না।

            
PHASE 6
Same-scope URL collection
html.parser ও urllib.parse দিয়ে homepage link/sitemap URL সংগ্রহ; off-scope link fetch নয়।

            
PHASE 7
JavaScript hints
সর্বোচ্চ ৩টি same-host JS file GET, Python regex দিয়ে endpoint clue; সম্ভাব্য secret value report-এ redact।

            
PHASE 8
Parameter names
urllib.parse দিয়ে সংগৃহীত URL থেকে নাম inventory; values রাখা বা test payload পাঠানো হয় না।

            
PHASE 9
Passive security review
আগে দেখা response header ও redacted JS indicator দেখে manual-review finding। Port scan/exploit বা injection test নয়।
