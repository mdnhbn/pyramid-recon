Reference page-এর tool-গুলো নিচে phase অনুযায়ী map করা হয়েছে। Python backend নিজে safe bounded method চালায়; শুধু local machine-এ Subfinder বা Amass install থাকলে Phase 2-তে passive mode চলে। অন্য binary install হয়েছে বলে ধরে নেওয়া হয় না। প্রতিটি external tool-এর বর্তমান availability backend থেকে দেখা হবে।

          

            
PHASE 0
Scope & prerequisites
Python domain validation, ownership attestation, provider consent, runtime and optional local CLI availability. Go/pipx/Git/curl/wget are reference prerequisites, not automatically installed.

            
PHASE 1
Passive Recon & OSINT
crt.sh CT query and dnspython A/AAAA/MX/NS/TXT summary. Censys, Shodan, DNSDumpster, Whois and ViewDNS are listed; they are not automatically queried.

            
PHASE 2
Subdomain discovery
Python DNS resolver handles candidate names; installed subfinder and amass may run passive mode. dnsx behavior is covered by dnspython. Puredns/MassDNS brute force is not run.

            
PHASE 3
Live host verification
One homepage request to the exact root host, pinned to a resolved public IP with redirects disabled. ProjectDiscovery httpx and gowitness are not invoked.

            
PHASE 4
Technology fingerprinting
Python HTML/header fingerprints provide WhatWeb-style hints. Wappalyzer extension and BuiltWith are not queried by the backend.

            
PHASE 5
Content discovery
Reads root robots.txt/sitemap.xml, then checks at most 8 fixed paths serially and skips robots-disallowed paths. ffuf, feroxbuster and dirsearch wordlists are not run.

            
PHASE 6
URL & endpoint discovery
Internet Archive CDX historical lookup plus Python same-host crawler capped at 8 pages. Katana/hakrawler binaries are not invoked; forms and redirects are not followed.

            
PHASE 7
JavaScript & secrets
Python URL and credential-pattern checks on at most 3 root-host scripts, equivalent to a limited SecretFinder/jsluice review. Matched values are redacted.

            
PHASE 8
Parameter discovery
Parameter names only from observed and archived URLs (ParamSpider-style). Arjun is not invoked because it sends active parameter probes.

            
PHASE 9
Passive security review
Nuclei templates, SQLMap, Ghauri, Dalfox and Nmap are listed but not run. No injection, exploitation, database extraction or port scan occurs.
